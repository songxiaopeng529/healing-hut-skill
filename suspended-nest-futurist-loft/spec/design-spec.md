# 悬浮织巢·生物未来主义 LOFT V2

## 空间原型

- 两层挑空空间，右侧为两层通高雪景窗。
- 左后方设置实体夹层，二楼床完全落在楼板上。
- 一楼主体不是传统沙发，而是一张低位悬吊式沙发床。
- 左后方设置折板式转角楼梯，避免遮挡右侧窗景。

## 右侧窗景

- 右墙采用带真实结构框架的通高弧形落地窗。
- 窗外为茂密翠绿竹林与雨雾山谷。
- 天气为强烈斜向暴雨，竹竿与竹叶明显向同一风向弯曲。
- 玻璃外侧有大水滴、连续雨痕和湿润反光。
- 窗帘位于窗框两侧，不遮挡主要景观。

## 一楼悬吊沙发床

- 椭圆形软包沙发床离地约 35cm，不悬在挑空区域。
- 由一组独立门式钢架承重，钢架固定在地面和顶部横梁。
- 四组短拉索连接沙发床隐藏刚性底框，受力对称。
- 沙发床具有高软包靠背、厚坐垫、围合侧翼和安全扶手。
- 下方铺设完整厚羊毛地毯和软垫，即使跌落也不接触硬地面。
- 周围保留至少 90cm 通道。

## 二楼卧室

- 普通软床放置在左后方实体夹层楼板上，不再悬吊。
- 床靠实体后墙，距离临空栏杆至少 1.5m。
- 二楼设置连续 1.1m 护栏。
- 包含衣柜、床头柜和观雪阅读椅，不设置第二间卧室。

## 楼梯与通行

- 左后侧采用钢木折板式 L 型楼梯。
- 第一跑从一楼左后方起步，到标准矩形平台后转向 90°。
- 第二跑连续到二楼入口，最后一级与楼板齐平。
- 楼梯、平台和夹层均有连续护栏。
- 不允许书架、灯具或家具侵入楼梯通道。

## 室内体验

- 一楼设置小型封闭壁炉、软凳、毛毡屏风、厚地毯和低矮茶几。
- 室外为冷绿色风雨竹林，室内使用珊瑚粉、覆盆子红、水绿色、柠檬黄、珠光白和浅色木材。
- 深色钢梁改为珠光白或香槟银饰面，减少工业与老旧感。
- 使用彩色花瓣吊灯、流线型软家具、亚克力边桌、现代植物画和渐变织物。
- 女性化表达应明亮、时尚、成熟，不使用糖果公主风或复古沉重木作。
- 厨房与厕所位于镜头后方服务核心，不进入主画面。

## 禁止项

- 二楼悬空床。
- 悬吊沙发没有独立承重钢架。
- 拉索连接玻璃、窗帘或灯具。
- 悬吊沙发下方为裸露硬地面。
- 楼梯断层、栏杆堵住出口、室内飘雪。
- 多余楼层、神秘房门、蓝紫霓虹赛博风。
